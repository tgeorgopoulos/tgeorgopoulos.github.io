DeskAgent

A local voice-controlled agent that turns a spoken request into a step-by-step plan, reads it back, and only acts after you confirm. It drives a browser with Playwright to read pages and collect information from websites that allow automated access, saves each successful task as a recipe that replays in seconds, and blocks credential entry and unapproved sends in code rather than in a prompt.

Windows automation · MCP server

Recipe Engine

Records a desktop or browser workflow once and replays it in seconds with no AI model in the loop. Every step is located by its UI Automation identity, verified after it runs, and refused if it would type a password or press Send, Buy or Delete. In a 50-run reliability test, Notepad and Calculator replays succeeded 50 out of 50 with a median of about 2 seconds.

Texas Hold'em Poker AI First AI project

My first AI project. A poker engine built from scratch with NumPy and no poker libraries: a hand evaluator, Monte Carlo win probabilities, a strategy engine that recommends bet, call, raise or fold from pot odds and position, and simulated opponents. To test whether it was actually learning, I set one opponent to go all-in every hand and checked whether the AI picked up on it. It did.
